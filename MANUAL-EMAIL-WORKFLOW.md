# Manual email workflow

This release does not send email and does not create Outlook drafts.

1. Find or select a contact.
2. Generate the personalised email.
3. Use **Copy subject** and **Copy email**.
4. Paste them into Outlook or another email client and send manually.
5. Choose **Mark emailed manually** to update the lead status.

No Microsoft 365 API connection or Microsoft environment variables are required.
